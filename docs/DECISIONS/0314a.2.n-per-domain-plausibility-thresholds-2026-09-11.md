## Section 3 · Constitutional interpretation (15 founder-authored rules · verbatim)

1. These thresholds are **plausibility guardrails, NOT proof of truth.**
2. Passing a threshold does NOT establish truth.
3. Failing a threshold does NOT automatically establish falsity.
4. A value outside the threshold produces the R-01 deterministic plausibility finding defined by this ADR-0314a.2.n.
5. Missing/null values are `UNKNOWN` where the attribute is optional or legitimately absent.
6. `UNKNOWN` must never be converted to `FALSE`.
7. `UNKNOWN` must never be converted to `very_low` confidence.
8. A value of zero is valid **only where the founder-authored threshold explicitly permits zero.**
9. Do not infer thresholds for attributes not listed above.
10. Do not inherit thresholds from another Domain.
11. Do not silently create country-specific variants.
12. Runtime observations may report that a threshold appears too strict or too broad, but runtime observations cannot modify these values.
13. Any future amendment requires an explicit founder-authorised versioning-policy ADR.
14. The Truth Engine must record `plausibility_threshold_version` with every applicable evaluation.
15. The Router must surface the relevant threshold/verdict provenance when applicable.

These 15 rules are locked. They are not amendable except through explicit founder-authored versioning-policy ADR (per D-17 amendment pattern locked 2026-09-11 in Stage 1 Founder Decisions).

## Section 4 · Special handling · founder-authored (verbatim)

### star_rating (accommodation)

- `null` / unrated → `UNKNOWN`
- Valid range: `1–5`
- **Zero must NOT be used as an inferred substitute for "unrated"** (preserves §7.7 H1 · `unknown` ≠ `very_low`)
- Guardian rejects a write where the source data records `star_rating=0` as a proxy for "not rated"

### admission_fee (attractions)

- Zero is **explicitly valid** because **free attractions exist** (e.g. public parks · beaches · viewpoints · religious sites with no entry charge)

### stock (commerce · mp_product)

- Zero is **explicitly valid** because **an item can legitimately be out of stock** (a product with 0 current units is still a real product · not implausible)

**Interpretation constraint:** any future Truth Engine implementation MUST distinguish between:
- **Zero legitimately** (allowed at attributes explicitly permitting zero · e.g. admission_fee · stock)
- **Zero as unknown-proxy** (forbidden · use `UNKNOWN` instead per §7.7 H1)

## Section 5 · Enforcement implications (doctrine · not implemented by this ADR)

- **Guardian rule:** a `plausibility_threshold` row's `founder_authored` field must be `true` for enforcement · Guardian rejects thresholds without founder-authored provenance
- **Guardian rule:** the 14 canonical values above are enforced when Guardian evaluates R-01 · any value outside the founder-authored range produces R-01 deterministic finding per Rule 4 above
- **Guardian rule:** null values on optional attributes produce `UNKNOWN` (per Rule 5) · Guardian never converts `UNKNOWN` to `FALSE` or `very_low` (per Rules 6-7)
- **Guardian rule:** value=0 on `stock` or `admission_fee` PASSES (per Section 4) · value=0 on `star_rating` FAILS with reason `zero_as_unknown_proxy_forbidden` (per Section 4)
- **Truth Engine rule:** every R-01 verdict records `plausibility_threshold_version = plausibility_threshold.v1.0.0` per Rule 14
- **Router rule:** presentation surface (Chat · NEX1 · retrieval) surfaces the applied threshold + verdict when a value was rejected or flagged (per Rule 15) · never silently drops the verdict
- **Anti-inference rule:** Master AI must not add thresholds for attributes beyond the 14 listed above (per Rule 9) · runtime observation of a threshold gap surfaces a **founder-facing recommendation** · Master AI does not autonomously add rows
- **Anti-inheritance rule:** Master AI must not inherit thresholds from Domain A when authoring policy for Domain B (per Rule 10) · e.g. `accommodation.rooms=2000` does NOT imply `services.rooms=2000` because services doesn't have a rooms attribute · it has chair_count
