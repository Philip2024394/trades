## Section 1 · Deterministic rules structure (locked)

**A cross-record contradiction is issued only when a deterministic governed rule establishes logical incompatibility.** Master AI does NOT invent contradictions. Founder authors specific rules.

**4 deterministic rule categories (locked structure):**

1. **Same subject · logically-incompatible claims** — e.g. `is_open_24h = true` AND `closing_hour = 22:00` on the same subject
2. **Numeric claim outside R-01 tolerance** — e.g. two sources claim `star_rating: 3` vs `star_rating: 5` on the same subject (both within R-01 plausibility · but disagreeing)
3. **Categorical claims from different registered authorities (per R-05) disagree** — e.g. authority A cites `category='hotel'`, authority B cites `category='villa'` for the same subject
4. **Same-record version history shows unauthored regression** — e.g. a founder-declared authoritative value flips back after a subsequent lower-authority update

**Founder authors specific rules in a future ADR (candidate slot ADR-0314a.2.r.pop) per attribute-type · per Domain · per rule-category.**

## Section 2 · FORBIDDEN bases · locked (per R-20 doctrine)

**These bases MUST NEVER produce a contradiction verdict:**

- **Similarity-based verdicts** (text similarity · embedding proximity)
- **Keyword-overlap verdicts** (shared vocabulary tokens)
- **LLM-alone verdicts** (LLM permitted only as candidate-flag producer · never as sole verdict source)
- **Missing-data-as-falsity** (per §7.7 H1 · missing data = UNKNOWN · never CONTRADICTION)
- **Scope-mismatch-as-contradiction** (claims about different scopes are not contradictions · they are complementary)

**Any Guardian implementation that produces a contradiction verdict on one of these forbidden bases is a G-2 non-bypass violation.**
