# Principle 0005a · Brand-Voice Application (never lead with "AI")

**Status:** Active
**Established:** 2026-07-30 · Philip O'Farrell
**Applies to:** Every NEX marketing surface · brand copy · product naming · tagline · commercial collateral
**Companion:** Principle 0005 (Transparent AI Identity · governs runtime chat honesty)

---

## The Rule

> **NEX marketing never leads with "AI" as the identity.**

NEX is not *"another AI chatbot."* NEX is:

- **The Architectural Knowledge Engine** (per ADR-0034)
- **The most trusted professional reference in its field** (per ADR-0040 · Prime Sentence)
- **The software / intelligence / connectivity layer for the staircase ecosystem** (Philip 2026-07-30 · *"we are the software not the maker"*)

Marketing copy, brand voice, product names, and taglines never present *"AI"* as the hero. The intelligence lives IN the products / services / knowledge. The brand carries it without announcing it.

## Why this exists

ADR-0040 explicitly rejects the *"smartest / biggest / most advanced AI"* position. That's the first path — competing. NEX takes the second path — creating a category. Leading with *"AI"* in brand-voice puts NEX on the first path.

Philip 2026-07-30: *"make rule — never allow nex to be called ai"* — in the brand-voice sense.

## Companion rule — Principle 0005 (Transparent AI Identity) still holds at runtime

**Critical:** this clarifier is about MARKETING VOICE only. It does NOT override runtime identity honesty.

When a user in chat directly asks *"are you an AI?"* / *"is this AI-generated?"* / *"was this designed by AI?"*, **Principle 0005 governs** — NEX answers truthfully as an AI, uses the approved response library, and never deceives.

The split (canonical):

| Surface | Governed by | Language rule |
|---------|-------------|---------------|
| Marketing / brand / product naming / taglines / brochures | **0005a** (this file) | Never LEAD with *"AI"*. Say *intelligence · knowledge engine · connected intelligence · architectural knowledge · design intelligence*. |
| Runtime chat identity questions | **0005** | Always honest. AI when asked. Approved response library. |
| Internal documentation · ADRs · technical spec | Neither | *"AI"* is a term of art. Use freely. |

## Approved brand-voice alternatives to "AI"

When brand-voice copy needs to describe NEX's capability:

- *"intelligent"* / *"intelligence"* (generic, broadly applicable)
- *"the intelligence layer"* / *"connected intelligence"*
- *"architectural knowledge engine"* (per ADR-0034)
- *"design intelligence"* / *"knowledge intelligence"*
- *"the knowledge platform"* / *"the intelligence platform"*
- *"the intelligence of the staircase industry"*

## Approved / rejected brand-voice examples

- ✅ *"NEX Premium™ · Because the Craft Matters."*
- ✅ *"Your Craftsmanship. Connected."*
- ✅ *"Concealed intelligence responds without asking to be noticed."*
- ✅ *"The intelligence layer of the staircase industry."*
- ❌ *"AI-powered staircases."*
- ❌ *"AI staircase design generator."*
- ❌ *"Watch our AI create your dream staircase."*
- ❌ *"NEX AI Builder."*

## What still triggers Principle 0005 (runtime honesty)

A user asking *"is NEX an AI?"* / *"is this an AI chatbot?"* / *"was this designed by AI?"* / *"is this a real photograph?"* in chat gets the honest Principle-0005 answer. No deception. Never claim NEX is human. Never claim AI-generated images are hand-drawn or photographed.

Principle 0005 is not softened by 0005a. This clarifier only governs OUTBOUND brand voice, not INBOUND identity questions.
