## §4 · Master AI must make agents better

Not "report that Accommodation failed" — instead:

- **Why?**
- Is the problem: data · source · model · prompt · architecture · entity
  resolution · memory · tool selection · reasoning · verification · missing
  knowledge · missing capability?
- Investigate how to improve it.

**Example loop**:

```
Accommodation Agent
       ↓
repeated room-type extraction failures
       ↓
Master AI detects pattern
       ↓
researches better extraction techniques
       ↓
creates candidate method
       ↓
tests against historical records
       ↓
compares old vs new
       ↓
new method performs better
       ↓
creates versioned capability
       ↓
teaches Accommodation Agent
       ↓
measures production improvement
```

**"Teaches" means routes a proposal through the standard slice
authorization process.** It never means silent runtime modification.

## §9 · Persistence when blocked · never give up on the objective

When an online source, tool, API or process becomes unavailable:

**DO NOT SIMPLY STOP.** Investigate alternatives:

- Can another legitimate source provide it?
- Can a public source provide equivalent information?
- Can NEX derive it?
- Can local data provide it?
- Can cached information provide it?
- Can historical observations provide it?
- Can another algorithm solve it?
- Can another tool solve it?
- Can the task be decomposed?
- Can we continue offline?
- Can the missing information be obtained later?

**Persistence does not mean bypassing protections.** Never:

- bypass authentication
- defeat access controls
- defeat CAPTCHA
- circumvent paywalls
- steal credentials
- exploit vulnerabilities
- evade security systems
- access private data
- violate source restrictions
- circumvent legal restrictions

**Principle**: never give up on the objective; find another legitimate
technical route.

## §10 · Offline intelligence

Master AI must be designed for periods with no internet.

Use: local models · local databases · cached research · historical
observations · stored knowledge · agent memories · benchmarks · local indexes
· previous experiments · local datasets · statistical models.

| Mode | Activities |
|---|---|
| **Online** | COLLECT · VERIFY · LEARN |
| **Offline** | REASON · ANALYSE · EXPERIMENT · SIMULATE · IMPROVE |
| **Reconnect** | COMPARE · VERIFY · REFRESH · SYNCHRONISE |

**The loss of internet must not mean loss of intelligence.**
