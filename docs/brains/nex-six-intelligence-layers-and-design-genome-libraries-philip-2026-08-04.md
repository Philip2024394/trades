# Six Intelligence Layers + Design Genome 7 Libraries

## The Constitutional Line (Philip 2026-08-04)

*"Pixels become a delivery format · while the accumulated design knowledge becomes the enduring asset. That is the architectural distinction that will make NEX difficult to compete with."*

This is not a new CORE pin · it's a REFRAMING of the ones already in place (Renderer Never Makes Aesthetic Decisions · Not an Image Generator · Pixels are Temporary). Together they now say: **the renderer is a Delivery Platform endpoint · the knowledge is the moat.**

## The Six Intelligence Layers (Philip 2026-08-04)

Object-level learning is not enough. To become world-class Nex adds SIX new layers · each strengthened by every upload.

### 1 · Marketing Layout DNA

Learns the complete COMPOSITION of a marketing template:

```
Headline → Subheading → Benefits → Product Hero → CTA → Contact → Website
```

**Home:** Already SHIPPED as Pattern Library PatternDNA (`src/lib/nex/pattern-library/`). This doctrine confirms the mapping.

### 2 · Brand DNA

Every upload strengthens one or more brand-personality profiles: Industrial · Luxury · Trade · Premium · Modern · Family · Minimal · Corporate.

**Home:** SHIPPING this session · `src/lib/nex/brand-dna/`.

### 3 · Colour Grammar

Instead of hex values · store semantic MEANING:

```
Black   → strength · premium · engineering
Gold    → luxury · value
Blue    → trust · professional
Green   → eco · nature · home
Red     → urgency · action · sales
White   → clean · minimal · space
```

Future campaigns can request *"make it feel trustworthy"* instead of `#0057B8`.

**Home:** SHIPPING this session · `src/lib/nex/colour-grammar/`.

### 4 · Editable Region Intelligence (extended)

Every editable region carries: max characters · safe font size · minimum contrast · max lines · allowed alignment · preferred hierarchy. Enables Nex to rewrite adverts automatically without breaking the design.

**Home:** already partially SHIPPED as SafeArea in `hero-image.ts` + PatternDNA safe_zones. This doctrine extends it with the additional constraints listed above · Colour Grammar contract enforces `minimum contrast` at pattern-apply time.

### 5 · Campaign Family Intelligence

Instead of 4 separate adverts · Nex knows they belong to ONE campaign that produces many outputs: Poster · Facebook · Instagram · Website Hero · Email Header · Vehicle Wrap · Business Card · Leaflet · Trade Show Banner.

**Home:** SHIPPING this session · `src/lib/nex/campaign-family/`.

### 6 · Object Relationships (biggest improvement · Philip)

Typed edges beyond "compatible_with":

```
Loft Ladder
  → requires  → Loft Hatch
  → mounted_in → Ceiling
  → inside    → Room
  → used_for  → Loft Access
```

**Home:** SHIPPING this session · `src/lib/nex/relationship-library/` (distinct from `relationship-engine` which is per-scene composition · this is the TAXONOMY of typed object relationships).
