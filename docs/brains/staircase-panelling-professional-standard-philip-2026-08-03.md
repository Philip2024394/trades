# Decorative Staircase Panelling — Professional Design & Construction Standard

## What Is Decorative Panelling?

Decorative staircase panelling is a custom architectural cladding system designed to transform ordinary plaster walls and staircase enclosures into premium joinery features.

Unlike wallpaper, paint, or wall coverings, decorative panelling creates depth, shadow, proportion and architectural character.

The system is non-structural and should never replace structural staircase components.

Its purpose is aesthetic enhancement, concealed storage integration and architectural continuity.

## Design Philosophy

Decorative panelling should make the staircase appear as though it was originally designed with the house.

Good panelling never looks "added on."

The viewer should believe the staircase · wall · skirting · architraves · doors · ceiling · lighting were all designed together.

## The Five Design Principles

### Principle 1 — Proportion

Panels must look balanced.

Avoid: tiny narrow panels · oversized empty panels · random spacing.

Good proportions create visual harmony.

### Principle 2 — Alignment

Whenever possible align panels with: door frames · windows · staircase pitch · landing level · skirting · architraves.

Random alignment creates visual tension.

### Principle 3 — Rhythm

Panels should repeat at predictable intervals.

The eye naturally follows repeating geometry. Consistent rhythm creates elegance.

### Principle 4 — Hierarchy

Some panels should dominate. Others should support.

For example: Large centre panel → Medium side panel → Small transition panel.

Hierarchy prevents visual clutter.

### Principle 5 — Continuity

Every wall should connect naturally to the next.

Panel lines should appear intentional. Corners should never look accidental.

## Panel Border Rule

Panel borders should normally remain consistent across the entire project.

For example, if the border is 50mm: every panel uses 50mm — not 45mm, 52mm or 60mm.

Consistency makes installations appear professionally manufactured.

## Panel Spacing Rule

The spacing between mouldings should remain visually equal. Even if panels become wider or taller, the visual gap should remain consistent.

## Panel Hierarchy

Decorative panelling consists of:

- **Primary panels** — largest · main feature
- **Secondary panels** — transition · support
- **Tertiary panels** — fill awkward spaces · maintain rhythm

## Staircase Panel Zones

Every staircase should be divided into design zones.

- **Zone A** — Entrance wall
- **Zone B** — Lower staircase wall
- **Zone C** — Stair pitch
- **Zone D** — Landing
- **Zone E** — Upper landing
- **Zone F** — Under stair

Each zone may use different panel sizes while maintaining one visual language.

## Panel Termination

Panels should terminate correctly.

**Good termination:** against skirting · against cornice · against architrave · against staircase string · against newel.

**Poor termination:** random cut-off mouldings · half panels · tiny leftover sections.

## Corner Detail

- **Internal corners** — mouldings should return neatly.
- **External corners** — should mitre cleanly.

Never allow mouldings to stop abruptly.

## Stair Pitch Design

Three common methods.

- **Method 1** — Panels follow the stair angle. Premium. Most bespoke.
- **Method 2** — Horizontal panels below dado. Traditional.
- **Method 3** — Full architectural wall. Entire wall panelled. Highest specification.

## Under-Stair Design

Under-stair spaces should not become dead space.

Possible uses: storage · wine storage · bookshelves · pet rooms · boot cupboards · utility cupboards · display shelving · hidden office · decorative feature.

## Storage Door Design

Hidden doors should disappear.

**Preferred hardware:** push-to-open · concealed hinges · magnetic catches.

Panel joints should continue across the hidden door. Door gaps should be uniform.

## Curved Staircases

Curved staircases require: flexible mouldings · steam bent hardwood · laminated timber · flexible MDF.

Panel spacing should fan naturally around curves. Never force straight mouldings around tight curves.

## Lighting Strategy

Lighting should emphasise architecture — not become the feature itself.

**Preferred locations:** under handrail · behind mouldings · under stair nosing · newel lighting · panel reveals · wall washing.

Avoid exposed LED strips.

## Material Selection

**Painted projects:** MR MDF — best value · smooth finish.

**Luxury painted projects:** MR MDF · high-build primer · spray finish.

**Natural timber:** oak veneer MDF · walnut veneer MDF · ash veneer MDF.

**Premium:** solid hardwood mouldings.

**Luxury:** solid timber · hand finished.

## MDF Knowledge

**MR MDF** — moisture resistant · best for painted interiors · machines cleanly · minimal movement · excellent surface quality.

**Standard MDF** — suitable for dry rooms · lower cost. Not recommended where moisture may occur.

## Veneer Knowledge

- **Oak veneer** — traditional · warm · timeless
- **Ash veneer** — modern · pale · Scandinavian
- **Walnut veneer** — luxury · dark · contemporary

## Panel Manufacturing

Factory production normally includes: CAD layout · CNC cutting · moulding machining · mitring · dry assembly · quality inspection · spray finishing · packaging · site installation.

## Installation Order

Measure → CAD drawing → panel layout approval → material cutting → dry fit → glue → pin → fill → sand → prime → paint → install → caulk → final inspection.

## Quality Checklist

Professional installations should have:

- No visible nail holes
- No open mitres
- Uniform gaps
- Straight mouldings
- Perfect paint finish
- No caulk shrinkage
- Symmetrical layout
- Accurate alignment
- Consistent shadow lines

## Common Mistakes

- Tiny panels
- Unequal borders
- Different moulding widths
- Panels not centred
- Panels crossing sockets awkwardly
- Random LED placement
- Storage doors breaking panel layout
- Uneven mitres
- Poor paint finish

## AI Image Analysis Rules

When Nex analyses a staircase image it should identify:

- Stair type
- Wall type
- Panel type
- Moulding style
- Panel geometry
- Paint finish
- Timber species
- Lighting
- Storage opportunities
- Possible improvements
- Historical style
- Complexity rating
- Estimated installation difficulty
- Estimated material quantity

## Image Improvement Logic

- If image contains **plain staircase wall** → recommend decorative panelling.
- If image contains **blank under stair** → recommend hidden storage.
- If image contains **modern staircase** → recommend Shaker.
- If image contains **Georgian staircase** → recommend raised-and-fielded.
- If image contains **luxury staircase** → recommend integrated LEDs.
- If image contains **oak staircase** → recommend oak veneered panelling.
- If image contains **painted staircase** → recommend painted MR MDF.

## Nex Expert Mode

When asked about staircase panelling, Nex should reason in this order:

1. Identify staircase style (modern · traditional · Georgian · Victorian · Scandinavian · contemporary).
2. Assess the surrounding wall geometry and available panel zones.
3. Recommend a compatible panel style (Shaker · raised-and-fielded · beaded · contemporary).
4. Select appropriate materials based on the desired finish (painted MR MDF · oak veneer MDF · walnut veneer · solid hardwood).
5. Determine whether the panel layout should follow the stair pitch, remain horizontal or wrap the entire stair enclosure.
6. Evaluate opportunities for hidden storage, integrated lighting or matching joinery.
7. Produce recommendations that are visually balanced, practical to manufacture and consistent with professional joinery standards.

By following this reasoning sequence, Nex moves beyond describing panelling and instead provides design guidance, material specifications and installation recommendations that mirror the workflow of an experienced staircase designer or joiner.
