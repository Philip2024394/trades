## Part 3 · Skills Marketplace (Extensibility)

Every Skill is a self-contained capability that the Router can invoke.

### Skill Declaration (mandatory)

```yaml
skill_id: banner_generator
skill_name: AI Banner Designer
supported_intents: [Create, Improve]
required_inputs:
  - business_name
  - brand_colors
  - platform (facebook, instagram, website)
  - purpose (sale, launch, seasonal, general)
required_outputs:
  - image_url (banner)
  - platform_variants[] (facebook_cover, instagram_story, website_hero)
connected_services:
  - facebook_page_api (post)
  - instagram_api (post)
  - website_cms (upload)
  - image_manifest (log per ADR-0024)
pricing: per_generation | subscription_included | free_tier_limited
```

## Composition with Existing Constitution

- **Fifth Law (Completion):** every AI Specialist completes the work; Skills are the mechanism by which completion happens.
- **First Law (Commitment):** every Skill invocation creates a visible Workspace artefact.
- **Fourth Law (Authority):** significant Skill actions require per-action confirmation or standing permission.
- **Capabilities Not Features (L1):** an Industry Pack is a coherent user-facing outcome (one Pack = one Workspace transformation).
- **Simplicity Rule (L1):** two Skills solving the same problem → keep the simpler.
- **Nine Principles:** every AI Specialist / Pack / Skill must strengthen at least one Principle.
