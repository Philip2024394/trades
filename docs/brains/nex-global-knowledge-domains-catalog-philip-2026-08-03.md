## The Domain Priority Matrix

Priorities are determined by three signals combined:

1. **Immediate revenue opportunity** — will paying users appear the day this ships?
2. **Composition with existing work** — does it inherit from already-authored Brains?
3. **Cross-domain value** — will other domains reuse this knowledge?

**Highest priority for authoring next (2026-08-04 onwards):**

- **Kitchens** — composes with Staircase manufacturing · Home Renovator Pack unlocks
- **Marketing** — composes with Skills Marketplace + Cake Business Pack
- **Building Regulations** — cross-cutting (Staircase already needs it · Kitchens · Extensions · Loft all need it)
- **CRM** — cross-cutting (every business workspace needs it)
- **Website Design** — composes with AI Website Agency specialist

**Second wave (2026-Q4):** Doors · Windows · Flooring · SEO · Sales · Interior Design.

**Third wave (2027):** the rest, driven by user demand + Industry Pack downloads.

## The Governance Rule

**No new domain enters Nex without:**

1. A Brain doc file following the Domain Template.
2. At least 20 authored FAQs (Rule c: named_expert or Philip-approved).
3. At least 5 A+ reference images with subject_domain tag.
4. A registered AI Specialist mapping (which Specialist(s) handle this domain).
5. Router Tag registration (which universal verbs it handles).
6. Workspace Object schema (what artefacts users create in this domain).

The Router will refuse to route to an incomplete domain (composes with ADR-0033 Quality Over Quantity).

## Enhancement Opportunity

Every competitor tries to cover many domains via ONE model. Nex covers many domains via MANY structured domains, each following the same template, each independently reviewable, each independently improvable. That structure is what lets Nex be simultaneously DEEP in every domain and BROAD across all of them — a combination no monolithic LLM can achieve.
