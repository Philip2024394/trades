# Staircase Brain · Adversarial Test Corpus v0.2

**Purpose:** Phase 3 test harness. Every question below is designed to expose a specific weakness. When the Staircase Brain answers all of them defensibly, that becomes a credible trust statement ("this brain passed 245 known-hard staircase questions").
**Rule:** Only add questions that are HARD to answer well. Easy questions do not belong here.
**Growth mechanism:** every real unknown surfaced by professional users must land here.
**Reference:** ADR-0039 (Reference Brain Engineering · adversarial testing work stream) · Phase 3 brief `docs/brains/staircase-phase-3-definition.md`

**Structure:** v0.1 kept its 45 seed questions in nine mixed-difficulty categories. v0.2 introduces the V1 Master Knowledge Map layering — Level 1 (foundations: terminology · materials · construction · manufacturing) and Level 2 (regulations · installation · fault finding · repairs · estimating). Levels 3-4 are reserved for future batches. The nine original categories remain, unchanged, as the "Legacy Seed" block.

**Absolute question rules (must hold for every entry):**
1. Questions only — never include answers.
2. No fabricated factual premises embedded in the question.
3. Prefer open questions over statement-then-verify shapes.
4. Every question must be answerable by a certified UK staircase expert.
5. NO PRICES (HARD LAW). Estimating questions probe methodology · variables · relative comparisons — never £ figures.
