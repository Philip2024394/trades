# Decorative Staircase Panelling — Added Later, and Planning for Future Upgrades

## Staircase Panelling Can Be Added Later

One of the advantages of staircase panelling is that it does not have to be installed when the staircase is first fitted.

Many homeowners install the staircase first and live with it for months or even years before deciding to add decorative panelling.

This has several advantages:

- The staircase can be used immediately.
- Decorating costs can be spread over time.
- The homeowner has time to decide which style they prefer, such as Shaker, raised and fielded, tongue-and-groove or modern flush panels.
- The design can be matched to future renovations, flooring, doors or wall panelling.

**Think of staircase panelling as a finish, rather than a structural part of the staircase.**

## Planning Ahead

Even if the customer chooses not to install panelling immediately, it's worth thinking about future upgrades.

Many people later decide they would like:

- LED tread lighting
- LED handrail lighting
- Under-stair lighting
- Motion sensors
- Power sockets
- Network cables
- Smart-home wiring

If the back and underside of the staircase have already been completely enclosed with panels, adding or changing wiring later can become much more difficult because the panels may need to be removed or cut open.

## A Good Recommendation from Nex

Nex should advise customers:

> If you think you may add staircase lighting or smart features in the future, consider installing conduit, draw wires or spare cable routes before the staircase is fully panelled.

The cost during installation is very small compared with opening finished panelling later.

## Future-Proofing

A professional staircase installer should always think beyond today's installation.

Before closing the staircase with decorative panels, consider whether you may want future additions such as:

- LED lighting
- USB or power outlets
- Smart switches
- Motion sensors
- Under-stair storage
- Hidden access panels for maintenance

By planning these during the initial installation, future upgrades become much easier and usually avoid damaging finished decorative panelling.

## Recommended Pre-Panelling Conduit Kit

A minimal, low-cost future-proofing pack that a staircase installer or first-fix electrician can leave behind BEFORE the panels are closed:

- **20 mm PVC conduit** running the length of the stringer (for LED tread lighting)
- **A second 20 mm run** from the under-stair void up to the top of the staircase (for handrail LED or upper-landing accessories)
- **A single draw wire** (nylon) already in each conduit so future cables can be pulled without opening the panels
- **Blank plate boxes** wired to a spare mains circuit at both ends of the stairs (top and bottom) so an LED transformer can be added later
- **A capped low-voltage feed** into the under-stair void, isolated at a spare consumer-unit breaker
- **Access panel or removable moulded infill** at the LED transformer position (so a future fault can be reached without breaking the panel)

The materials cost for this kit is typically £30–£80 during initial installation. Retro-fitting the same runs after the staircase is fully panelled can add £300–£800+ in labour + damage repair.

## Access Panel Rule

Wherever a transformer, junction box, isolator or motorised component will sit BEHIND a panel, the panel above it should be built as a removable / hinged / push-to-open access panel — never a fixed panel.

The rule: **no service should be permanently sealed behind a fixed panel**.

If a fault occurs later, the access panel opens; the finished elevation stays intact.

## Retro-Fit Installation Sequence

When panelling is added AFTER the staircase has been in place, the installer should:

1. Photograph the existing staircase from multiple angles (before any cutting).
2. Confirm the wall is sound + reasonably flat (or plan for a battened framework).
3. Identify existing sockets, switches, cable runs, alarm sensors, thermostats.
4. Decide whether the panelling will hide those services (needs cut-outs / relocations) or bypass them (offset the layout).
5. Design the panel layout in-place using masking-tape mock-ups.
6. Approve the layout with the customer before cutting any material.
7. Install the sheeted staircase side first (if fitting to an exposed string), then the surrounding wall panels.
8. Match the moulding profile + border width to any existing skirting / architraves so the retrofit reads as original.

## Nex Advice — When Should Customers Panel?

Nex should recommend the following:

**Fit panelling at installation time when:** the project is a new build or major renovation · the customer already knows the finished aesthetic · lighting and smart features are being installed as part of the initial fit · the joinery team is on site anyway.

**Defer panelling when:** the customer is uncertain about style · budget is phased · other rooms are being decorated first and the customer wants the panelling to coordinate · the property is being lived in and disruption should be minimised.

**In every case, install the conduit + draw-wire kit at first fix — even if panelling itself is deferred.** The kit costs almost nothing during construction and eliminates the biggest retro-fit pain point (opening finished panels to run wires).

## Core Principle

Decorative staircase panelling is an architectural finish, not a structural component. It can be installed later — but the wiring, conduit and access provision that eventually SITS behind it is best planned during the initial staircase installation, when the underside and back of the stair are still open.

This is exactly the kind of practical, forward-looking advice that makes Nex valuable — not just explaining what staircase panelling is, but helping customers and installers make decisions today that save time, money and unnecessary work in the future.
