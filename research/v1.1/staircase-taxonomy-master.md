## The classification layers

The single most important research finding: **staircase attributes belong to distinct layers that describe the same staircase from different angles.** A stair can be simultaneously `timber + straight + mono-stringer + open-riser + oak treads + glass balustrade + oak handrail`. These are not competing options — they are seven independent classification statements. The taxonomy must hold every layer as a first-class dimension.

### Layer A — Material family
The overall material family that defines how the stair looks and how it is made.
Common values: **timber · metal (steel · aluminium · stainless · brass · bronze) · glass · concrete · stone · composite · mixed** (e.g. timber + glass, metal + glass, timber + metal, timber + metal + glass) · **bespoke**.

### Layer B — Geometry / form
How the stair travels through space in plan.
Core values: **straight flight · quarter turn (L-shape) · half turn (U-shape / dog-leg) · winder · kite winder · continuous winder · balanced (fanned treads keeping walking-line depth) · spiral (central column) · helical (open well, no column) · curved (smooth radius) · bifurcated / split · imperial (grand bifurcated) · scissor · double-helix · floating (visual class) · space-saver / paddle / alternating-tread · ships ladder · loft / attic ladder**.

### Layer C — Structural / support system
How the stair is held up. Independent of geometry.
Core values: **closed string · cut string / open string · wall string · outer string · double string · mono stringer / central spine · saw-tooth / zig-zag stringer · cantilever · bolt-fixed (Bolzentreppe) · suspended / tension-supported · central column (for spiral) · folded-plate (Faltwerktreppe)**.

### Layer D — Riser configuration
Whether the vertical face between treads exists and what it is.
Core values: **closed riser · open riser · partial riser · glass riser · timber riser · metal riser · feature-bar riser · slatted riser · no riser** (= open).

### Layer E — Tread system
What the customer's foot lands on.
Core values by material: **solid timber (oak · walnut · mahogany · ash · beech · maple · pine · sapele · iroko · plus regional species: jarrah · blackbutt · spotted gum · tasmanian oak · ironbark · merbau · rimu · matai · kauri · tawa · beech NZ · red oak US · white oak US · hard maple · hickory · cherry · walnut US) · engineered timber · veneered · stone / marble / granite / limestone / quartz · concrete · metal (steel · stainless · aluminium) · glass (laminated toughened) · carpet insert · carpet runner · mixed / composite**.

### Layer F — String / edge appearance
How the side of the stair reads visually. Overlaps with Layer C but is a visual (not structural) statement.
Core values: **closed / cut / open / wall / outer** + **exposed vs concealed tread ends · skirt board · scotia moulding · floating edge · apron / apron lining · spandrel · base rail**.

### Layer G — Balustrade
The whole barrier system on the open side (regional names differ — see below).
Core values by material: **timber (traditional spindles · square spindles · turned spindles · contemporary timber · slatted) · metal (mild steel · stainless brushed / polished · powder-coated · black steel · brass · bronze) · glass (framed · semi-frameless · frameless · with posts / clamps / channel / timber handrail / metal handrail) · cable / wire (horizontal · vertical) · combination**.

### Layer H — Handrail
The graspable top rail. Regional profile terminology varies.
Core values by material: **timber (oak · walnut · mahogany · pine · painted) · metal (stainless · mild steel · brass · bronze) · glass-mounted / cap · wall-mounted · continuous · combination**. Fittings: **volute · monkey's tail · turnout · easing (up / over) · gooseneck · rosette · return · easer · stop end · 90° bend**.

### Layer I — Newels / posts
The vertical structural post anchoring the balustrade.
Core values: **starting newel · landing newel · intermediate newel · angle newel · balcony newel · box newel · turned newel · square newel · feature newel · half newel · metal / stainless post · glass support post · hidden support · finial · newel cap · post-to-post vs over-the-post systems**.

### Layer J — Landing configuration
Level platforms interrupting flights.
Core values: **quarter landing · half landing · intermediate landing · top landing · bottom landing · floor landing · split landing · open landing · closed landing · gallery / balcony landing · winder landing** (turn without landing).

### Layer K — Specialist forms
Stair types that require their own commercial and often regulatory treatment.
Core values: **spiral · helical · curved · alternating tread / paddle / space-saver · ships ladder · loft / attic ladder · loft / attic stair (fixed) · industrial · service · fire escape · exterior / garden · monumental / grand · bifurcated / imperial · double / split · scissor · double helix · floating · cantilever · sculptural · bespoke architectural**.

## The three critical concept distinctions

### 1 · Spiral vs helical vs winder vs curved

**Spiral** = winders radiating from a common centre WITH a load-bearing central column.
**Helical** = winds around an open central well, NO column.
**Winder** = individual tapered / wedge tread inside an otherwise-straight flight, used in place of a landing.
**Curved** = continuous smooth radius, not a helix pattern.

These four are DIFFERENT concepts. Every code across every researched country distinguishes them. Marketing and consumer speech routinely collapse them. The taxonomy MUST preserve all four with separate records.

Multi-lingual mapping (see cross-cutting draft for full table): DE `Spindeltreppe` = spiral · `Wendeltreppe (ohne Spindel)` = helical. IT `scala a chiocciola` = spiral · `scala elicoidale` = helical. FR `escalier en colimaçon` = spiral (popular) · `escalier hélicoïdal` = professional (often merges both — verify with photo). ES `escalera de caracol` = spiral · `escalera helicoidal` = helical (Spain-usage; LatAm ambiguous). DK/NO `spindeltrappe/spindeltrapp` = spiral · `vindeltrappe/vindeltrapp` = helical. **SE uniquely** treats `spiraltrappa`, `vindeltrappa` and `spindeltrappa` as synonyms per Swedish Academy — do not translate SE `vindeltrappa` to DK/NO `vindeltrappe` without a structural qualifier.

### 2 · Floating vs cantilever

**Floating** is an appearance/visual class — any stair with no visible support.
**Cantilever** is one structural way to achieve that look — treads projecting from a wall with no visible free-end support.

A mono-stringer (single central beam) stair reads as floating but is not a cantilever. A bolt-fixed (Bolzentreppe) stair may read as floating but is neither cantilever nor mono-stringer. Marketing uses "floating" for all three; specifications must record both a marketing tag (floating) and a structural tag (cantilever / mono / bolt-fixed).

### 3 · String vs stringer vs skirt board

**String (UK/IE) = Stringer (US/CA/AU/NZ)** — same structural component (the inclined side beam that carries the treads). No semantic divergence; regional label only.

**Open string = Cut string (UK)** — synonyms in UK trade. The top edge of the stringer is cut in a step-profile so tread ends are visible.

**Skirt board (US)** = wall-side finish trim, **explicitly NON-structural**. In the UK, the parallel term is "wall string" which IS structural. This is a genuine transatlantic false friend and one of the most common technical confusions.

## The regional balustrade vocabulary map

The whole-assembly barrier concept has a canonical local name in every country:

| Region | Whole assembly | Vertical component | Top rail (graspable) |
|---|---|---|---|
| UK / IE / AU / NZ | Balustrade | Baluster / Spindle | Handrail |
| US / CA | Guard / Guardrail / Railing (US); Balustrade in high-end residential | Baluster / Spindle / Picket (Southern US) | Handrail |
| DE / AT / CH-DE | Geländer · Brüstung (solid) · Parapetto (Italian CH) | Stab / Füllstäbe | Handlauf |
| FR / BE-FR / CH-FR | Garde-corps (code) · Rampe (commercial: balustrade+handrail) · Balustrade (ornamental) | Balustres / Barreaux | Main courante |
| IT / CH-IT | Ringhiera (flight) · Balaustra (landing) · Parapetto (code) | Balaustri / Aste | Corrimano · Mancorrente (regional) |
| ES | Barandilla · Balaustrada (architectural) · Antepecho (parapet) | Balaustres / Barrotes | Pasamanos |
| NL / BE-NL | Balustrade · Leuning · Hekwerk (industrial) | Spijl / Baluster | Trapleuning · Leuning |
| SE | Räcke · Glasräcke · Smidesräcke | Ballister | Handledare |
| NO | Rekkverk | Balustre / Spile | Håndlist |
| DK | Gelænder | Balustre | Håndliste |
| FI | Kaide · Suojakaide · Avokaide · Lasikaide | Pinna | Käsijohde |

**Critical distinction (US only):** "Handrail" and "guardrail" are DISTINCT code concepts. Guardrail = fall-prevention (IBC 1015). Handrail = graspable (IBC 1014). In UK the words are colloquially fused because "balustrade" covers the fall-prevention function separately.

## Customer-language principle

Every technical option requires two layers:

- **Professional name** (canonical): e.g. `Cut String Staircase`
- **Customer explanation** (plain English): e.g. `Exposed Step Ends — The ends of the treads are visible, creating a more decorative and open appearance.`

The system NEVER asks the customer to hold professional vocabulary as pre-existing knowledge. Every decision point offers a plain-English explanation, always. And every decision point offers **"I'm not sure"** as a first-class option that opens a visual side-by-side comparison of the primary alternatives (see decision tree file for the option sets).

---

## What the taxonomy is NOT

- Not a measurement system — never asks the customer to determine rise, going, pitch, headroom, structural spans, load capacity.
- Not a pricing engine — never estimates material, labour, install or final cost.
- Not a compliance system — never claims a specification is code-compliant.
- Not an engineering authority — never says a combination is "structurally impossible" without clear evidence.

Where a combination is unusual, the system says **"Specialist review required"** and hands off to the professional.
