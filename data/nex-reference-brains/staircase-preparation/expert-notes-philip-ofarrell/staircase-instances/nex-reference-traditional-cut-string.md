# Traditional Straight Flight Cut String Staircase

*This image shows a traditional straight flight, cut string timber staircase. It is an excellent reference example for teaching users what a cut string staircase looks like and how it differs from a closed string staircase.*

*In future lessons, this image can be paired with an equivalent closed string staircase so users can immediately see the difference between the two side string designs.*

## Staircase Type

- Straight flight staircase
- Single uninterrupted flight
- Closed riser construction
- Traditional timber staircase

## String Design

- Cut string (open cut string)
- The side string follows the shape of each tread and riser, creating a decorative stepped profile.
- The ends of the treads and risers remain fully visible.
- This exposed construction is the defining feature of a cut string staircase.

## Newel Posts

- Plain square newel posts
- Decorative caps
- Positioned at the bottom and top of the flight
- Approximately 90 mm square

## Handrail

- Traditional timber handrail
- Straight rake following the pitch of the staircase
- Connected directly between the two newel posts

## Balustrade

- Traditional turned timber balusters
- One baluster per tread
- Mortised into both the handrail and the staircase

## Treads and Risers

- Closed riser construction
- Square-front timber treads
- Standard timber risers
- Traditional stair nosing
- No decorative grooves or metal inlays

## Style

- Traditional residential timber staircase
- Factory-manufactured joinery
- Classic turned balustrade design

## Teaching Notes for Nex

*This image should be used as the reference example for a cut string staircase.*

The most important feature for users to recognise is the side string:

- The string is cut to follow the profile of every tread and riser.
- The ends of the treads and risers are exposed and visible.
- This creates the decorative stepped appearance associated with a cut string staircase.

When users later view an equivalent closed string staircase, they will clearly see that the side string is flat and continuous, with the tread ends hidden inside the string. Presenting both images together provides one of the easiest ways for beginners to understand the difference between cut string and closed string staircase construction.
