## Teaching Notes for Nex

*This image is particularly valuable because it demonstrates that a staircase can combine different construction types within the same installation.*

Users should learn that the overall staircase layout (half-turn/U-shaped) is different from the string construction:

- **The layout** describes the path of the staircase (straight, quarter-turn, half-turn, spiral, etc.).
- **The string type** describes how the treads are supported and whether their ends are exposed or concealed.

From this overhead view, the open balustrade side shows cut string construction, where the tread ends are visible. The wall side uses a closed wall string, where the structural string is concealed behind the wall finish. This combination is extremely common in residential staircases because only the open side is intended to be decorative.

*For Nex, this image is an excellent example for teaching that a single staircase can have one layout type but use different string constructions on different sides, helping users distinguish between the staircase's overall configuration and its construction details.*
