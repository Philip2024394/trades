# UK Approved Document K (England)

**Current version:** Approved Document K (England · 2013 edition incorporating 2015 amendments).

Approved Document K is the primary regulatory source for staircase design in England. Other UK regions use different documents (see Regional coverage below).

## Doc K clauses supplied by Philip (2026-07-25)

| Item | Value | Doc K clause reference |
|---|---|---|
| Uniformity rule (all steps same rise + going) | | Clause 1.1 |
| Private-stair definition (single dwelling) | | Clause 1.2 |
| Rise (min–max) | 150mm – 220mm | Clause 1.3 + Table 1.1 |
| Going (min) | 220mm | Clause 1.3 + Table 1.1 |
| Pitch (max) | 42° | Clause 1.3 + Table 1.1 |
| 2R + G rule | 550–700mm | Clause 1.4 |
| Headroom | 2000mm min above pitch line | Clause 1.6 |
| Loft-conversion headroom exception | 1900mm central axis, 2000mm at one side | Clause 1.7 |
| Handrail sides | one if width <1m, both if ≥1m | Clause 1.36 |

**Handrail height and balustrade height** are known reliably as handrail 900–1000mm and balustrade 900mm on stair / 1100mm on landing, but the exact clause reference is not yet in the authored source and should be added when confirmed.

## Critical honesty rules (authored discipline)

- These numbers are Approved Doc K (England). Wales has its own AD K; Scotland uses the Technical Handbook Section 4; Northern Ireland uses Technical Booklet H. When quoting the specific numbers, say "England"; when generalising, say "check the version that applies to your region".
- **Doc K sets minimums, not maximums.** There is no hard cap on going, width, headroom, landing size — max is set by comfort, available space and budget. A wider going than 280mm starts to feel like walking on a stepped platform rather than climbing — a design limit, not a regulatory one.
- **Historic staircases in listed buildings** may retain non-compliant original dimensions where Building Control accepts the historic character. This should be acknowledged rather than dogmatically insisting current Doc K applies to a Georgian original.
- **Doc K revisions:** the values above reflect the 2013 revision. Verify against the current published version on gov.uk before quoting for a specific project.
