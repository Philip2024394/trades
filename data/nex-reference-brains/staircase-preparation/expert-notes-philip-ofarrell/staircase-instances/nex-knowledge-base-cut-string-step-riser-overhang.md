# NEX Knowledge Base

## Cut String Design – Step and Riser Overhang Style

### Purpose

*This image shows the side profile of a cut string staircase, allowing the user to view one of the available cut string design options. It illustrates how the tread and riser project beyond the face of the cut string, creating a traditional stepped appearance.*

### String Design Style

**Design Name:**
**Step and Riser Overhang Cut String**

In this design:

- Each tread extends past the face of the cut string.
- Each riser also extends past the face of the cut string.
- The exposed edges create a layered, stepped profile along the side of the staircase.
- This is a popular traditional design used on many hardwood staircases.

### Typical Overhang

The visible projection of the tread and riser beyond the string is typically:

- **Approximately 25 mm** (varies by manufacturer and design requirements).

*This overhang creates depth, shadow lines, and a more decorative appearance compared with a flush cut string.*

### Components Visible

- Cut string (side view).
- Tread with approximately 25 mm overhang.
- Riser with approximately 25 mm overhang.
- Turned timber balusters.
- Square timber balusters.
- Hardwood finish.

### Design Characteristics

- Decorative stepped profile.
- Traditional UK staircase appearance.
- Clean shadow lines between components.
- Enhanced visual depth.
- Suitable for both painted and hardwood staircases.

### NEX Recognition

When NEX identifies this detail, it should recognise:

- **This is a cut string design option, not a staircase type.**
- The image is demonstrating the relationship between the cut string, treads, and risers.
- Both the tread and riser project beyond the face of the string by approximately 25 mm, producing the classic overhang detail used in traditional staircase manufacture.

> **NEX Note:** *The exact overhang dimension is a design choice and varies between manufacturers. While approximately 25 mm is common, the projection should remain consistent throughout the staircase to maintain a balanced and professional appearance.*
