# Handrail

The handrail is the graspable top rail of a staircase balustrade.

## Traditional UK profile

- Rounded / domed top surface for grasping (traditional UK profile, used for generations)
- Straight sides
- **Groove cut into the underside** — accepts the tops of the balusters
- Sits at top of balustrade at Doc-K-compliant grasping height

## Standard sizes (UK / Ireland)

Handrail thickness matches the baluster width it hosts:

| Baluster width | Handrail thickness |
|---|---|
| 32mm | ~32mm (slim balustrade — modern minimalist) |
| **41mm** | **41mm — current UK/Ireland standard** |
| 44mm | 44mm — traditional/older, standard before mass production |
| 50mm | Larger (~50mm) |
| 60mm | Largest (~60mm) |

## Baluster fitting

Balusters slot into the top-of-baserail groove and bottom-of-handrail groove. Slips (small cut-to-length spacer strips) fit in the groove above and below each baluster to lock them in place.

## Sizing rule for heavy balusters

**For heavy balusters (50mm+), always size up all four balustrade components at the same level:**

1. Baluster width increases
2. Handrail thickness increases (groove must match baluster)
3. Baserail thickness increases (groove must match baluster)
4. Newel post size increases (balustrade weight loads increase; newel takes the tenon loads)

This proportional-scaling rule keeps the balustrade visually balanced AND structurally sound.
