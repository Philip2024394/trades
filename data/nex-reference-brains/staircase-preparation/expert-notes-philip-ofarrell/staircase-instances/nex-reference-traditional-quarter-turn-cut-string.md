# Traditional Quarter-Turn Cut String Staircase

*This image shows a traditional quarter-turn (L-shaped) timber staircase with a 90° landing. The staircase changes direction once before continuing to the upper floor. It features cut string construction, closed risers, turned balusters, decorative newel posts, and a bullnose starting step.*

*The design combines painted timber joinery with stained hardwood components to create a traditional two-tone appearance.*

## Staircase Classification

**Staircase Type**

## Walking Line

The walking line begins at the centre of the bullnose starting step, travels straight up the lower flight, crosses the centre of the landing, turns 90 degrees and continues up the second flight to the first floor.

The walking line provides a comfortable and natural route up the staircase while maintaining consistent tread spacing.

## Staircase Layout

The staircase consists of:

- Bullnose starting step
- Lower straight flight
- Intermediate landing
- Upper straight flight
- Landing balustrade
- First-floor gallery balustrade

This arrangement creates an elegant entrance while reducing the overall floor space compared with a long straight staircase.

## Teaching Notes for Nex

*This image is an excellent teaching reference because it demonstrates several important staircase concepts in a single design.*

Users can learn how to recognise:

- A **quarter-turn staircase** from its 90-degree change in direction.
- A **cut string staircase** by observing the exposed tread ends and decorative stepped string profile.
- The difference between **painted joinery** (strings, risers, balusters and newel posts) and **stained hardwood components** (treads, handrails and newel caps).
- The function and location of major stair parts including the bullnose starting step, treads, risers, strings, handrails, balusters, newel posts, landing and gallery balustrade.

*Later, Nex should present a staircase with the same layout but using closed string construction. Because the layouts are similar, users will immediately recognise that the only major visual difference is the side string: a cut string exposes the ends of the treads and risers with a decorative stepped profile, while a closed string has a smooth, continuous side that conceals the tread ends. This side-by-side comparison provides one of the clearest ways to understand the distinction between the two staircase constructions.*
