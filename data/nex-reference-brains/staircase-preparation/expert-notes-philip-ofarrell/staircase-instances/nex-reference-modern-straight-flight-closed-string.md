# Modern Straight Flight Closed String Staircase

*This image shows a modern straight flight timber staircase with a closed string design and painted string and risers. The staircase combines stained timber with black metal balusters to create a clean contemporary appearance.*

*Unlike a traditional cut string staircase, this staircase has a smooth continuous side string that completely conceals the ends of the treads and risers.*

*This is an excellent teaching image for Nex because it clearly demonstrates the appearance of a closed string staircase, making it ideal for comparison with a cut string design.*

## Teaching Notes for Nex

*This image should be used as the reference example for a modern closed string staircase.*

It clearly demonstrates the defining characteristics of closed string construction:

- The side string forms one smooth, continuous diagonal line.
- The ends of the treads and risers are completely concealed within the string.
- There is no decorative stepped profile as found on a cut string staircase.
- The overall appearance is clean, simple and contemporary.

*This image pairs exceptionally well with a traditional cut string staircase. When users compare the two, they can quickly recognise that:*

- **A closed string staircase** hides the tread and riser ends behind a continuous side string, creating a sleek and modern appearance.
- **A cut string staircase** exposes the tread and riser ends with a decorative stepped profile, giving a more traditional and detailed appearance.

*This direct visual comparison helps users understand that the string design is one of the most important features used to identify different staircase constructions.*
