## Teaching Notes for Nex

*This image is an excellent example of how staircase geometry, materials and under-stair design work together.*

The staircase should first be identified as a **quarter-turn (L-shaped) staircase**, because the direction changes by approximately 90 degrees. The turn is achieved using three kite winder steps, not a square landing, making it a **quarter-turn winder staircase**.

The construction is a **closed string staircase**, with the tread and riser ends concealed behind smooth continuous strings. Unlike a cut string staircase, there are no exposed tread ends or decorative stepped profiles.

Another important teaching point is the **material consistency**. The treads, risers, strings, handrails, balusters and newel posts are all finished in matching dark walnut timber, creating a unified appearance that differs from staircases using painted strings or contrasting balustrades.

Finally, this image demonstrates how the under-stair void can be transformed into bespoke fitted cabinetry. Here it has been designed as a premium wine cellar with integrated lighting, showing that while the staircase construction remains unchanged, the space beneath can be adapted for specialist storage, display units, home offices, libraries or other custom joinery solutions.

*This helps users understand that staircase type and under-stair design are separate aspects of the overall staircase design.*
