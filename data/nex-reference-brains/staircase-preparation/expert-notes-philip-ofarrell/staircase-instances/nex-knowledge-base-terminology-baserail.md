# Baserail

The baserail is the bottom rail of a two-part balustrade rail system in the UK/Ireland traditional construction style.

## Profile

- Flat top with a **groove cut into the top face** — accepts the bottoms of the balusters
- Moulded sides
- Sits on top of the string board, spanning the length of the flight

## When present

Not present on all UK staircases (some go straight into the string housing) — the baserail is a newer construction style.

## Baluster fitting

Balusters slot into the top-of-baserail groove and bottom-of-handrail groove. Grooves stop left-right movement (baluster held in the channel). **Slips** (small cut-to-length spacer strips) fit in the groove above and below each baluster to stop the balusters moving along the length of the rails.

## Standard sizes (UK / Ireland)

Baserail thickness matches the baluster width it hosts:

| Baluster width | Baserail thickness |
|---|---|
| 32mm | ~32mm |
| **41mm** | **41mm — current UK/Ireland standard** |
| 44mm | 44mm — traditional/older |
| 50mm | Larger (~50mm) |
| 60mm | Largest (~60mm) |

## Sizing rule for heavy balusters

For heavy balusters (50mm+), size up all four balustrade components at the same level (baluster + handrail + baserail + newel).
