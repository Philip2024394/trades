# Newel Post

A newel post is the principal vertical post at a staircase's flight endpoints (bottom, top, and at quarter/half-turn corners). It anchors the strings, the balustrade, and the first tread.

## Typical sizes (UK/Ireland)

- **75mm** — light traditional
- **90mm** — standard modern
- **120mm** — larger / feature
- Larger sizes for heavy balusters (see Baluster article)

## Four canonical construction rules for newel post at string endpoint

### Rule 1 — String thickness centered on newel post

The string's thickness (typically 32mm) must be centered on the newel post's cross-section, **regardless of newel size (75mm / 90mm / 120mm / larger)**. The newel post extends equally on both sides of the string. For a 90mm newel with 32mm string, the newel projects (90 − 32) / 2 = 29mm on each side of the string plane.

**Why:** structural — puts the string load through the newel's centerline (strongest axis). Also visual — the newel reads as the visual "anchor" with the string tucked centrally into it.

### Rule 2 — String tenons ~50mm into newel (haunched joint)

The string's end is reduced to a tenon that fits **inside the newel post approximately 50mm deep**. The newel has a mortice cut to receive this tenon. This is called a **haunched mortice-and-tenon joint**.

**Why:** mechanical joint — the tenon carries the shear load from the string into the newel. Glued + wedged for permanence.

### Rule 3 — Bullnose (first tread) 12mm haunched into newel

On the first tread (typically bullnose or D-end): the tread is **12mm haunched inside** the newel post's inner face, positioned approximately **25mm back from the newel's front edge**. The tread doesn't stop at the newel face — it cuts into the newel body.

**Why:** locks the first tread solidly into the newel (which is the most-loaded newel — first-step traffic + handrail leverage).

### Rule 4 — First riser haunched into newel back

The first riser is also haunched into the newel body, approximately 45-50mm from the newel edge.
