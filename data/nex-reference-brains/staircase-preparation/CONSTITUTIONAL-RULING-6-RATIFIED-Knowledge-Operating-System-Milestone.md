## Constitutional Milestone

This ruling formally marks the transition of the project.

### Phase 1

**Teach Nex about staircases.**

Primary objective:

- Build staircase knowledge.
- Capture expert craftsmanship.
- Establish the Staircase Brain.

### Phase 2

**Teach Nex how knowledge itself works.**

The project now focuses on how Nex:

- acquires knowledge
- organizes knowledge
- retrieves knowledge
- combines knowledge
- explains knowledge

*This represents a change in architectural direction rather than a change in project purpose.*

---

## Standard v1 Confirmed as Project Constitution

Standard v1 is now recognised as the constitutional reference for every future authoring decision.

The governing question is no longer:

> *"How should we write this?"*

It is now:

> ***"Does this comply with Standard v1?"***

*This elevates Standard v1 from documentation guidance to constitutional governance.*

---

## Longest-Lifespan Architectural Decision

The separation between:

- **Evidence**
- **Runtime**

is formally declared the project's longest-lived architectural principle.

*Regardless of future technology, models, databases, or programming languages, this separation is expected to remain valid because it reflects how trustworthy knowledge is produced rather than how software is implemented.*

---

## Three-Phase Roadmap

### Phase 1 · Knowledge Operating System

Build the foundations that allow expert knowledge to exist in a structured form.

### Phase 2 · Question Router

Develop the intelligence responsible for selecting:

- relevant knowledge
- appropriate evidence
- suitable explanations
- correct reasoning path

### Phase 3 · Multiple Specialist Brains

Extend the Knowledge Operating System to additional domains while reusing the same constitutional architecture.

Examples include:

- Staircase Brain
- Door Brain
- Flooring Brain
- Cabinet Brain
- Construction Brain

*Each becomes an implementation of the same operating system rather than an independent project.*

---

## Five-Stage Knowledge Lifecycle

Knowledge is now formally defined as progressing through five stages.

| Stage | Purpose |
|---|---|
| **Authored** | Expert knowledge is created. |
| **Governed** | Standards ensure consistency and quality. |
| **Retrieved** | Relevant knowledge is selected. |
| **Combined** | Multiple sources are synthesised into one answer. |
| **Explained** | Nex communicates the reasoning clearly to the user. |

*Every stage is governed by Standard v1.*

---

## Standard v2 Candidate — Knowledge Confidence Layer

Preserved as a future constitutional evolution.

**Proposed maturity levels:**

| Level | Meaning |
|---|---|
| **Canonical** | Authored and approved as authoritative. |
| **Reference** | Reliable example or accepted industry practice. |
| **Observed** | Seen in real projects or images but not yet broadly validated. |
| **Emerging** | Pattern observed repeatedly but still undergoing evaluation. |

### Reality Signal Required

Standard v2 will only be constructed if reality demonstrates that retrieval quality or user trust suffers because knowledge of different maturity levels is treated as equally authoritative.

Until that signal exists:

> ***Standard v1 remains sufficient.***

## Project Scope

Nex is now formally defined as:

> ***A Knowledge Operating System.***

It is not merely:

- a document repository

*Knowledge storage is only one capability within a much broader operating system responsible for transforming authored expertise into reliable explanations.*

*Phase 1 metrics such as article count or brain coverage are no longer the primary indicators of progress.*
