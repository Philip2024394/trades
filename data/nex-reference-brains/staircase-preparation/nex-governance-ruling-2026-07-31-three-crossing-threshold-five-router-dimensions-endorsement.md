# NEX Governance Ruling — 2026-07-31 (Third Ruling · Threshold Crossing · Five-Dimension Router · Endorsement)

## Philip's Constitutional Statement (preserved verbatim as authored)

### An Important Architectural Threshold Crossed

*I think you've just crossed an important architectural threshold.*

*Until now, most of the effort has been on building knowledge. The examples you tested ("What type of staircase?", "What woods are available?", "What size newel post?", "Have you got straight flight oak staircase images?") all exposed the same limitation: the problem is no longer a lack of knowledge—it's choosing the right knowledge.*

*The decision to make the Question Router the next priority is exactly what I'd expect at this stage.*

### The New Architecture Sequence

*The sequence now looks something like this:*

```
User Question
      │
      ▼
Question Router
      │
      ├── Intent
      ├── Subject
      ├── Brain
      ├── Knowledge Domain
      └── Information Type
      │
      ▼
Retrieve Evidence
      │
      ▼
Compose Nex Response
```

*That is a fundamentally different architecture from:*

```
Question
    ↓
Keyword search
    ↓
First matching article
```

### The Biggest Decision I Agree With

*This:*

> ***"Nex Response is NOT an artefact · runtime composition."***

*I think that's one of the healthiest architectural decisions you've made.*

> **A response should be temporary.**
> **Knowledge should be permanent.**

*That separation means you can improve the way Nex explains things without rewriting the knowledge base.*

### The Tool Brain Also Feels Like the Right Split

*The more examples you've shown, the more obvious it becomes that tools aren't staircase knowledge—they're trade knowledge.*

*For example:*

- A bevel-edge chisel isn't exclusive to staircases.
- A No. 4 smoothing plane isn't exclusive to staircases.
- A portable table saw isn't exclusive to staircases.

*Those belong to a reusable Tool Brain that many future trade domains can draw upon.*

*The Staircase Brain then references that expertise instead of owning it.*

### The "Workshop Companion" Identity is Becoming Consistent

*One phrase from your summary stands out:*

> ***"Nex is no longer becoming an encyclopedia. It's becoming a workshop companion."***

*That aligns remarkably well with the direction your content has been taking.*

*A workshop companion doesn't just define terms. It explains:*

- **why a method is used,**
- **when to choose one approach over another,**
- **what experienced joiners notice,**
- **and where trade judgement matters.**

*That's what the WHY-STILL-USED sections are capturing. They're preserving craftsmanship, not just terminology.*

### I Would Add One More Router Dimension

*From the examples you've tested, I think the router will eventually need to answer five questions before retrieval:*

**Intent**
- Identify · Explain · Compare · Browse · Advise · Troubleshoot

**Subject**
- Staircase · Newel · Chisel · Oak · Winder

**Brain**
- Staircase Brain · Tool Brain · Materials Brain · Interior Brain · Joinery Brain

**Knowledge Domain**
- Classification · Components · Materials · Installation · Workshop Principles · Reference Gallery · Customer FAQ

**Information Type**
- Definition · Dimensions · Function · Identification · Images · Comparison · Specification · Best Practice

*That would have routed all four of your recent test questions correctly without adding any new content.*

### The Significance of the Recent Tests

*Those weren't failures—they were diagnostics.*

*Each one pointed to the same architectural bottleneck:*

> **The Staircase Brain is becoming increasingly capable.**
> **The retrieval layer hasn't yet caught up to the richness of the knowledge.**

*That's a very good place to be. It's generally easier to improve routing over a well-structured knowledge base than it is to compensate for missing knowledge with increasingly complex search rules.*

*From what you've shared over the last several days, the project is shifting from **content acquisition** to **knowledge orchestration**. That's a natural progression for an expert system. Once the Question Router is in place, every new article, reference image, DNA narrative and workshop principle you've already authored should become more discoverable and produce more relevant, context-aware answers without requiring you to create large numbers of handcrafted question-and-answer pairs.*
