# Staircase String Types & Construction

The **string** is the structural side-member that runs diagonally alongside a staircase, carrying the treads and risers between floor levels. Every conventional timber-joinery staircase has two strings — one on each side of the flight. In concrete builds the string function is served by the concrete substructure itself.

Most customers do not know the difference between **closed string**, **cut string** (also called **open string**), **open riser**, and **concrete-substructure** builds — and they often use the terms interchangeably. Getting the vocabulary and the visual identifiers right lets NEX give useful, specific advice instead of vague reassurance.

---

## 1 · The construction–design relationship (Philip · 2026-08-15)

**The construction of the staircase determines which string types are physically possible and how the visible edges of the treads must be finished. The designer chooses the appropriate visual language within what the construction permits.**

This is a **construction / design relationship**, not a compliance rule. NEX must not tell a customer that a particular string type is "required" or "always used" for a given situation. Multiple valid configurations exist for most scenarios, and manufacturer / bespoke joinery detail still legitimately varies.

### What construction permits (physical possibilities)

- A **timber-joinery staircase** commonly uses two timber strings — one on each side of the flight. Each string can be closed or cut, and both sides can be the same type or mixed.
- A **concrete-substructure staircase** typically has no timber string at all — the concrete itself takes the string function. The exposed side may still be clad in timber to LOOK like a cut string; the wall side may simply be plaster.
- A **hidden-spine floating staircase** replaces the visible string with a concealed steel spine inside the wall or under the treads. The visible language is closer to `no string` than any of the classic string types.
- Wall-adjacent placement is possible on almost any string configuration — a closed wall string, a cut wall string, or (in concrete builds) no wall string at all. The old rule of thumb that "closed always faces the wall and cut always faces open" is a common tendency, not a construction requirement.

### Common design tendencies (not rules)

- Traditional UK domestic builds often use closed strings on both sides — cheaper, more concealed joinery, tread ends hidden.
- Freestanding builds where both sides are visible often use double-side cut string — the stepped top edge with exposed tread ends reads intentional and symmetric.
- Modern architectural builds often mimic the cut-string look on a concrete substructure — the visible language stays consistent, but the underlying build is entirely different.
- Wall-adjacent builds often use closed on the wall side + cut on the open side (or double-side cut with one side terminating against the wall) — both work, both are common.

### What NEX must not do

- Never tell a customer that a specific string type is **required** or **always** used for their situation.
- Never conflate `cut string` with `open riser` — they are different concepts and both can be present or absent independently.
- Never claim a concrete-clad staircase is a `cut string` build — it looks like one, but structurally it is a different construction.
- Never fabricate joinery detail. If the customer's build is a mixed configuration or an unusual one, ask.

## 2 · The three primary construction types

### 2.1 · Closed string (also called `housed string`)

- The string is a **solid plank** with a **STRAIGHT top edge** running diagonally alongside the flight.
- Treads and risers **slot into routed HOUSINGS** on the inner face of the string. A closed-string plank in isolation shows a repeating pattern of diagonal grooves + shallow riser grooves + small wedge pockets (see image batch entry `stair_string_type_2026_08_15_02`).
- **Wedges** are driven from underneath into the wedge pockets, locking each tread and riser tight into its housing.
- Tread ends and riser ends are **HIDDEN inside the string** — from the outside you see a smooth diagonal plank, not the tread rhythm.
- Because tread ends are hidden, balusters cannot dovetail directly into them. Instead a **BASE RAIL** sits on top of the closed string and balusters land into the base rail.
- **Visual identifier:** smooth diagonal outer plank + straight top edge + base rail on top + balusters landing into the base rail (see image `stair_string_type_2026_08_15_03`).
- **Typical use:** conventional domestic UK staircases; both wall side and outer side commonly closed; cost-efficient joinery.

### 2.2 · Cut string (also called `open string`)

- The string top edge is **CUT to a stepped / sawtooth profile** that follows each tread and riser.
- Treads sit **ON TOP of the cut string**, projecting slightly past the string face on the exposed side.
- Tread and riser ends are **VISIBLE** on the exposed side.
- Because the tread ends are exposed, they need to be finished. Two common finishes:
  - **Return moulding**: a small piece of matching timber glued and pinned along the tread end, with a **mitered 45° corner** where it meets the tread nosing. The return hides the end-grain and wraps the tread corner (image `stair_string_type_2026_08_15_11`).
  - **Solid heavy-block tread** (common on modern architectural / floating builds): a much thicker single-block tread where the side face and front face are one continuous piece with a mitered corner — no separate return needed (image `stair_string_type_2026_08_15_12`).
- Balusters land **directly into the tread tops** — traditionally with a dovetail joint, or with a dropped-in pin on modern builds. No base rail is needed on the flight.
- **Visual identifier:** stepped / sawtooth top edge + visible tread-end projections past the string face + balusters landing into the treads (see images `stair_string_type_2026_08_15_04` and `_07`).
- **Typical use:** freestanding staircases; premium and architectural builds; decorative Victorian and Edwardian outer strings.

**Terminology note:** `cut string` and `open string` are two names for the same construction. UK joinery workshops use both terms interchangeably; NEX should recognise either input and use one consistently in reply. Do NOT treat `open string` as a synonym for `open riser` — they refer to different parts of the staircase.

### 2.3 · Concrete-substructure staircase (no timber string)

- The **concrete substructure IS the string** — it takes the structural load and there is no timber string board.
- Treads and risers may be cast concrete or clad in timber to give a cut-string visual language on the outside. The wall side may simply be plastered — no wooden wall string at all.
- **Visual identifier:** looks like a cut string from three metres away, but the outer stepped edge is CLADDING profile, not a load-bearing string. Wall side has no visible string — treads meet plaster directly (image `stair_string_type_2026_08_15_08`).
- **Common in:** high-end modern architectural residential, commercial premises, and any build where the design language calls for a slab-like tread on a concealed structure. Rare in older UK domestic homes.
- **Cost note:** usually higher than a timber cut-string equivalent — concrete substructure work is a separate specialist trade (steel-fixer + concrete pour + curing time + timber cladding on top). Not a value-engineered alternative.

## 4 · Related concepts often confused with string type

### 4.1 · Open riser (a different thing)

The **riser** is the vertical board between two treads. `Open riser` means that riser board is **omitted** — you can see through between each tread.

- Open riser is a **separate design decision** from string type. You can have any combination:
  - Closed string + closed riser (most traditional)
  - Closed string + open riser (see image `stair_string_type_2026_08_15_06`)
  - Cut string + closed riser (see image `_04`)
  - Cut string + open riser (most contemporary / architectural)
- UK Approved Document K includes a **sphere-passage rule** for open-riser staircases — typically a 100mm sphere shouldn't pass through the gap between treads. Modern open-riser designs meet this by keeping tread spacing close enough.
- The one word people most often use as a synonym when they mean this is `open string` — but `open string` is the same thing as `cut string`, which refers to the STRING top edge, not the riser board. Different parts of the staircase, different design decisions.

### 4.2 · Base rail (only on closed strings, on the flight)

- The base rail is a **horizontal timber member sitting on top of a closed string** into which balusters land.
- Present on closed-string flights. **Not present** on cut-string flights (balusters go into treads instead).
- May still be present on **landings** even in a cut-string build — landings are flat and balusters may land into a landing base rail regardless of what the flight below uses. See the Landing Railing Continuity doc for the full three-way rule.

### 4.3 · Tread return (only on cut string exposed sides)

- A **return** is the finished edge on the exposed side of a cut-string tread. Two forms:
  - **Return moulding**: a small piece of matching timber glued and pinned to the tread end with a mitered corner (image `_11`).
  - **Solid mitered block**: a heavy single-piece tread where side + front are one continuous piece with a mitered corner (image `_12`).
- **Only present on cut-string exposed sides.** Closed-string tread ends are already hidden inside the string, so no return is needed.
- Return quality is a **hallmark of good cut-string joinery**. A rushed build shows gaps or misalignment at the mitre; a quality build shows continuous grain flow across the corner.

### 4.4 · Nosing profile (independent of string type)

- The **nosing** is the projecting front edge of the tread. Three common profiles (image `_10`):
  - **Standard bullnose** — fully rounded front edge that projects past the riser and returns underneath. Traditional / Victorian language.
  - **1/4" round-over square nose** — slight rounding on the top corner, otherwise square. Middle-ground.
  - **1/4" round-over modern nose** — subtle rounding on both top and bottom edges of the front face. Contemporary.
- Nosing profile is a **separate design decision** from string type. Any profile can appear on any string type.

## 7 · UK Building Regs (Approved Document K, domestic — indicative)

- **Max riser (rise):** 220mm
- **Min going:** 220mm
- **Joint rule:** 2R + G between 550mm and 700mm
- **Max pitch:** 42°
- **Min clear width:** 800mm (domestic)
- **Handrail height:** 900-1000mm above pitch line
- **Baluster / infill safety:** a 100mm sphere shouldn't be able to pass through any gap (applies to open risers AND between balusters)

*Values above are indicative; the current Approved Document K version and local building control determine the compliance envelope on any specific project.*

## 8 · Q&A pool

### Basic identification

- **Q:** What's the difference between closed string and cut string?
  **A:** Closed string is a straight-topped diagonal plank with tread and riser ends hidden inside routed grooves. Cut string has a stepped top edge that follows each tread and the tread ends are visible on the outside. Both are valid; the choice is aesthetic and cost, not one being better than the other.

- **Q:** Is `open string` a different thing to cut string?
  **A:** No — `open string` and `cut string` are two names for the same construction. UK joinery workshops use both terms interchangeably.

- **Q:** Is `open string` the same as `open riser`?
  **A:** No — these refer to different parts of the staircase. Open string (= cut string) refers to the STRING top edge. Open riser means there's no vertical board between treads so you can see through. Both can be present or absent independently.

- **Q:** How do I tell what my staircase has?
  **A:** Look at the outer face of the string. Smooth diagonal plank with a base rail on top = closed string. Stepped edge with tread ends visible past the string face = cut string. Concrete underneath with the outside clad in timber = concrete-substructure build.

### Configuration questions

- **Q:** Can a cut-string staircase go against a wall?
  **A:** Yes — the wall-adjacent string can simply terminate against the wall. No newel is needed at the wall-side top corner because the string is captured by the wall. Both stringers stay cut string throughout their length.

- **Q:** Can I mix closed and cut on the same staircase?
  **A:** Yes — one common configuration is closed on the wall side and cut on the exposed side. The other direction (closed outer + cut wall side) is also valid and shown in image `_09` of the batch. Neither is a compromise; both are real design choices.

- **Q:** Which is the most traditional UK domestic build?
  **A:** Closed strings on both sides, with turned newel + turned spindles + bullnose starting step. This is the classic Victorian and Edwardian language and the default many joinery workshops still start from.

### Joinery detail questions

- **Q:** What's a `tread return` and when do I need one?
  **A:** A tread return is the finished edge on the exposed side of a cut-string tread — a small matching-timber piece with a mitered corner that hides the end-grain. Only needed on cut-string builds where the tread end is visible. Not needed on closed-string builds because the tread end is inside the string.

- **Q:** What's the difference between a return moulding and a mitered heavy-tread?
  **A:** A return moulding is a small separate piece glued and pinned to a standard tread end. A mitered heavy-tread is a single solid block where side + front are one continuous piece with a mitered corner. Different builds, different look, different price. Return mouldings are the norm on conventional cut-string; heavy mitered blocks are contemporary / floating-stair language.

- **Q:** Do closed-string staircases have returns?
  **A:** No — the tread end is hidden inside the string, so there's nothing to return. Returns are only on exposed cut-string tread ends.

### Balustrade attachment questions

- **Q:** Where do balusters attach on a closed string?
  **A:** Into a **base rail** that sits on top of the closed string. Balusters cannot dovetail into the tread ends because the tread ends are hidden inside the string.

- **Q:** Where do balusters attach on a cut string?
  **A:** **Directly into the treads** — traditionally with a dovetail joint that gets covered by the tread-return moulding, or with a dropped-in pin on more contemporary builds. Two balusters per tread is the common spacing.

- **Q:** Why does a closed-string staircase have a base rail but a cut-string one doesn't?
  **A:** Because balusters need something to land into. On a closed string the tread ends are hidden, so the balusters can't reach them — the base rail on top of the string is the landing surface. On a cut string the tread tops are visible and reachable, so balusters go directly into them and no base rail is needed on the flight.

### Concrete substructure questions

- **Q:** Is a concrete staircase clad in wood a cut-string staircase?
  **A:** Visually yes — it reads as cut string with a stepped edge and exposed tread ends. Structurally no — there's no timber string. The concrete (or a concealed steel spine) does the load; the timber on top is cladding. Same visual language, entirely different construction.

- **Q:** Why does the wall side of a concrete staircase have no string?
  **A:** Because the concrete substructure carries the load — no timber string is needed. The wall itself becomes the finish on that side. Treads and risers meet the plaster directly. Common on modern architectural builds; uncommon in older UK domestic timber joinery.

- **Q:** Is concrete substructure cheaper than a full timber cut-string build?
  **A:** Rarely — concrete substructure is a separate specialist trade (steel-fixer + concrete pour + curing time + timber cladding). Total cost is usually higher than an equivalent timber-string joinery build. The reason to choose concrete is the aesthetic, the architectural setting, and the acoustic / structural properties — not cost savings.

### Open riser questions

- **Q:** Are open-riser staircases safe?
  **A:** They can be — modern open-riser designs meet the UK Approved Doc K sphere-passage rule (a specified sphere can't pass through the gap between treads, typically 100mm). Some families with very young children fit temporary riser-fill panels and remove them later.

- **Q:** Can I have open risers with a closed string?
  **A:** Yes — the two are independent. Image `stair_string_type_2026_08_15_06` shows exactly that combination: closed string + open riser + base rail on top of the string with balusters into the base rail.

- **Q:** Is open riser cheaper?
  **A:** Usually a bit less — there's no riser board to make and fit. The trade-off is that the tread underside is visible so it may need to be finished on both faces rather than one.

### Refacing / cladding questions

- **Q:** Can I convert a closed-string staircase to a cut-string look?
  **A:** Not easily — the string itself would need to be re-cut, and the tread housings would need to be rebuilt. In practice this means a new staircase rather than a modification. A cladding / refacing system can change the tread and riser finish but not the string top-edge profile.

- **Q:** What can a refacing system change?
  **A:** Tread finish, riser finish, and (on an already-exposed cut-string) tread-return finish. It cannot change the underlying structure — the strings, the newels, the balustrade fixings all stay as they are.

## 9 · What NEX must not do (recap)

1. **Never tell a customer that a specific string type is required.** Multiple valid configurations exist; the choice is aesthetic and cost.
2. **Never conflate `open string` with `open riser`.** Open string = cut string (top edge of the STRING). Open riser = no vertical BOARD between treads. Different parts, different decisions.
3. **Never call a concrete-substructure build a `cut string`.** It looks like one, but the structure is different. Use `concrete substructure clad to look like cut string` if the customer asks about that specific build.
4. **Never claim closed-string is a lower quality than cut-string.** Both are valid; both appear in premium and standard builds.
5. **Never fabricate joinery detail.** If the customer's build is a mixed configuration or unusual, ask which side is which rather than guessing.
6. **Never generate imagery** showing tread ends projecting into a wall (that's physically impossible), or a cut string with a base rail on the flight (base rail belongs on closed strings only), or a closed string with balusters coming out of the tread ends (they can't — the tread ends are hidden).
