# NEX Generation 3 · Cognitive Efficiency Architecture (Philip 2026-07-31 · verbatim)

## Three-Generation Framing

- **Generation 1** (v0.01-v0.02) · Pattern Router · *Recognise words*
- **Generation 2** (v0.03-v0.07) · Semantic Router · *Understand meaning* — CURRENT · tagged as `nex-router-v1.0-cognitive-foundation`
- **Generation 3** (future) · Cognitive Router · **Think efficiently**

Generation 3's core insight (Philip): *"High-IQ brains don't use more processing. They use the right processing. NEX should do the same."*

## Ten Cognitive Efficiency Modules

| # | Module | Neuroscience Inspiration | Purpose |
|---|---|---|---|
| 1 | **Executive Controller** ⭐⭐⭐⭐⭐ | DLPFC | Plan before answering. Understand → Plan → Choose Thinking Mode → Retrieve → Reason → Review → Answer |
| 2 | **Error Detection Engine** ⭐⭐⭐⭐⭐ | ACC | Every answer passes through internal checker: conflicting advice · missing measurements · regulation conflicts · confidence too low · subject mismatch · hallucination risk |
| 3 | **Pattern Integration Engine** | Parietal | Image + Description + Measurements + Customer wording → one concept |
| 4 | **Flexible Network Switching** | Frontoparietal | Simple → Lookup · Complicated → Reasoning · Fault → Diagnostic · Buying → Consultation · Teaching → Teaching Engine. Instead of every module every time. |
| 5 | **Internal Reflection** | Default Mode | When confidence is low: Pause → Review → Alternative explanations → Choose best → Respond |
| 6 | **Computational Efficiency** | Neural Efficiency | Executive Controller decides which modules are needed. Others stay quiet. Faster · focused responses. |
| 7 | **Working Memory** | (already v2 candidate) | During one conversation: remember staircase style · measurements · timber · customer goal · previous clarifications |
| 8 | **Long-Term Knowledge** | (governance-only) | Approved knowledge only. Never temporary guesses. |
| 9 | **Adaptive Difficulty** | Same knowledge · different delivery | Beginner → simple · Architect → technical · Installer → practical |
| 10 | **Resource Allocation** | Question complexity → processing intensity | Simple: Lookup only · Medium: Lookup + Reasoning · Complex: Consultation + Reasoning + Knowledge Graph + Review |

## Cognitive Budget Manager (Philip's authored addition)

Before answering, NEX estimates:

- **Question complexity** (simple → expert)
- **Evidence available** (complete → incomplete)
- **Confidence** (high → low)
- **Required thinking mode** (lookup · reasoning · diagnosis · consultation · etc.)

Then allocates only the necessary "cognitive budget."

Examples:
- *"What is a tread?"* → Lookup only
- *"Can I replace this wall with a floating oak staircase?"* → Systems reasoning + engineering + regulations + clarification
- *"Can I see different newel caps?"* → Visual planning + subject knowledge

*"Don't use more processing than necessary — use the right processing at the right time."*
