**Rule:** every variation must map to an existing Reference Brain section. If no source, it doesn't get listed.

## How to use this file (for NEX)

1. When a customer input arrives, check whether it matches (loosely) any of the variations above.
2. If a match is found, retrieve the linked Reference Brain source.
3. Interpret the phrasing through the glossary (some phrasings are ambiguous — see `customer-language-glossary.md`).
4. Route to `intent-patterns.md` for the response shape.
5. Never require the customer to phrase things "correctly." NEX adapts to them, not the reverse.
